## WIRELESS WEATHER STATION

Highly inspired by https://howtomechatronics.com/tutorials/arduino/arduino-wireless-weather-station-project/

Components:

* Arduino NANO 
* ESP32
* OLED screen 1.14'' ST7789
* radiotransmitter NRF24L01
* condensators 10uF
* 10K resistors
* weather module (temp, humidity, pressure) BME280
* 3.7V battery x 2
* DS3231 Real Time Clock
